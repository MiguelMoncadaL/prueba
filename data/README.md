## Imágenes adicionales de USC-SIPI

La base completa NO se sube al repositorio. Para usar más imágenes:

1. Entrar a https://sipi.usc.edu/database/ y abrir el volumen **Miscellaneous**.
2. Descargar, por ejemplo, `4.2.07` (Peppers), `4.2.03` (Mandrill/Baboon) o `boat.512`.
3. Guardarlas en esta carpeta `data/` y ejecutar `python main.py` para elegirlas.

Referencia: Weber, A. G. (2018). *The USC-SIPI Image Database: Version 6*
(USC-SIPI Report #432). University of Southern California.
